# Console Information Architecture

## Primary Navigation

```
Dashboard
 |
 ├── Agents
 |
 ├── Workflows
 |
 ├── Executions
 |
 ├── Tools
 |
 ├── Knowledge
 |
 ├── Security
 |
 └── Settings
```

## Agent Studio

Purpose: create and manage autonomous agents.

Sections:

- Identity
- System instructions
- Model selection
- Available tools
- Memory sources
- Permission policy
- Test playground

## Workflow Builder

Canvas based editor:

Nodes:

- Agent
- Tool
- Condition
- Human approval
- External API

Features:

- Drag and drop
- Versioning
- Debug execution
- Export/import workflow

## Execution Center

Provide observability:

- Active tasks
- Timeline
- Trace tree
- Tool execution details
- Failure recovery

## Security Center

Provide enterprise governance:

- Permission policies
- Agent capabilities
- Audit events
- Risk alerts
