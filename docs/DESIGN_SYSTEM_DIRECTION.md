# Design System Direction

## Visual Language

Target: professional AI infrastructure platform.

Reference style:

- Developer tools clarity
- Enterprise SaaS density
- Workflow visualization

## Components

Required reusable components:

### Agent Card

Displays:

- Agent identity
- Status
- Model
- Tools
- Permissions

### Workflow Node

Displays:

- Node type
- Input/output
- Runtime state
- Errors

### Execution Timeline

Displays:

- Agent reasoning stage
- Tool calls
- Events
- Duration

### Permission Badge

Displays:

- Allowed capability
- Restricted capability
- Security level

## Interaction Patterns

Prefer:

- Progressive disclosure
- Real-time execution updates
- Visual state changes
- Clear error recovery

Avoid:

- Chat-only interface
- Hidden tool execution
- Invisible permissions
